**Main thesis.** Pāṇinian grammar fixes a mantra's *form* (case, number, person, mood). Yāska's Nirukta fixes the *lawful range* of each word's meaning. Inside those two limits a mantra works as a schema with free variables, so it admits many internally consistent readings (*अनन्ता वै वेदाः*) without becoming arbitrary.
